# Termy Dictionaries

Downloadable offline dictionary packs for Termy.

Each source-language pack is published as a gzip-compressed SQLite database in
[GitHub Releases](https://github.com/live-sound/Termy-Dictionaries/releases).
Termy verifies the archive checksum, unpacks the database locally, and queries
it directly; large pack files are not stored in Git history.

## Coverage

Translations are the canonical translations present in Wiktionary, supplemented
with canonical translation links from the English pack when a source entry can
be matched safely. This is not a complete translation matrix: a sense may still
have no translation for the selected target language.

Some languages do not currently have a suitable native Kaikki edition. Their
packs contain that language's headwords and forms with English definitions; the
table identifies these packs explicitly. Termy may use its online service as a
fallback for missing entries or translations unless full offline mode is active.
